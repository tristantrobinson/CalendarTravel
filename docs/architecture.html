CalendarTravel — System Architecture

Traffic-aware drive-time blocks synced from a source Google Calendar into a dedicated travel calendar

Core sync job Triggers Google Cloud Calendars Local secrets / logs

Sync pipeline (each run)

  1. Load config from .env and authorize via token.json
  2. Fetch timed, located, non-cancelled events from the source calendar (next LOOKAHEAD_DAYS)
  3. For each event: pick origin (home or chained prior location) → query Routes API → compute block start/end
  4. Upsert tagged travel blocks in the travel calendar (create · update · skip if unchanged)
  5. Reconcile: delete travel blocks whose source event was removed, cancelled, or no longer qualifies
